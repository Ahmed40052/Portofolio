# Ahmed Ayman | Portfolio

A responsive personal portfolio website showcasing my background, skills, projects, and creative work in front-end development and video editing.

## About

I'm Ahmed Ayman, an Electronics and Communications Engineering student based in Sharkia, Egypt. I'm interested in front-end development, web accessibility, video editing, and color grading.

## Features

- Responsive layout for desktop, tablet, and mobile
- Dark and light themes
- Mobile navigation menu
- Sections for skills, education, experience, and projects
- Video-editing and color-grading portfolio projects
- Certificates, gallery, testimonials, and FAQ
- Audio and video introduction
- Contact information and social media links
- Scroll animations and active navigation states

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- [Font Awesome](https://fontawesome.com/)
- [Google Fonts](https://fonts.google.com/)

## Run Locally

No build tools or package installation are required. Clone or download the repository, then open `index.html` in your browser.
